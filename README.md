# GoBarber-Mobile

GoBarber-Mobile is the mobile version of the GoBarber platform, designed for barbershop and beauty salon owners to manage appointments and services on the go. This React Native application allows users to book appointments, view available service providers, and manage their schedules directly from their mobile devices.

## Features

- **Appointment Scheduling:** Users can book and manage appointments with their preferred service providers.
- **Service Provider Directory:** Browse and select from a list of available service providers.
- **Push Notifications:** Receive notifications about upcoming appointments and changes.
- **User Authentication:** Secure login and registration system for users and service providers.

## Installation

To get started with GoBarber-Mobile, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/go-barber-mobile.git
   cd go-barber-mobile
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Make sure the GoBarber API is running, as this mobile app relies on it for backend services. You can find the GoBarber API repository [here](https://github.com/renatosilveira99/go-barber-api).

4. Run the application:

   For Android:
   ```bash
   npm run android
   ```

   For iOS:
   ```bash
   npm run ios
   ```

5. Start the development server:

   ```bash
   npm start
   ```
